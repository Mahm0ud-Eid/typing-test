# Typing Test

A dynamic and responsive typing speed test web app built with modern front-end technologies. This project demonstrates careful attention to performance, user experience, and interactive design. Developed using HTML, CSS, and JavaScript, it offers real-time feedback, accurate typing metrics, and a smooth experience across devices. The codebase emphasizes clean structure and maintainability, making it a great reference for learning or improving front-end development skills.

## Features

- **Typing Speed Measurement:** Test your typing speed (WPM) and accuracy in real-time.
- **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.
- **Instant Feedback:** Highlights mistakes and shows live stats as you type.
- **Clean UI:** Simple, user-friendly interface focused on usability.
- **Well-structured Code:** Easy to read, extend, and maintain.

## Technologies Used

- **HTML5** for semantic structure
- **CSS3** for responsive and modern styling
- **JavaScript (ES6+)** for app logic and interactivity

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mahm0ud-Eid/typing-test.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd typing-test
   ```
3. **Open `index.html` in your browser:**
   - You can simply double-click the file or serve it using a local server for best results.
